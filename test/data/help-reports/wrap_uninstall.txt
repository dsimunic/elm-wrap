Usage:
  wrap uninstall PACKAGE [PACKAGE...]
  wrap uninstall --local-dev
  wrap uninstall --redundant [PATH] [--yes]

Remove packages from your Elm project.

Use --local-dev (run from within an Elm package directory) to remove the
current package from local-dev tracking.

Use --redundant in an application to find and remove redundant dependency
references at PATH (defaults to the current directory). Direct dependencies
that are still required are demoted to indirect.

This will also remove any indirect dependencies that are no longer
needed by other packages.

Aliases: 'remove' and 'package uninstall' can be used instead of 'uninstall'.

Examples:
  wrap uninstall elm/html           # Remove elm/html from your project
  wrap uninstall elm/html elm/json  # Remove multiple packages at once
  wrap uninstall --local-dev        # Remove current package from local-dev tracking
  wrap uninstall --redundant --yes  # Remove all redundant dependency references
  wrap uninstall --redundant ./app  # Remove redundant references from another app

Options:
  --local-dev                        # Remove current package from local-dev tracking
  --redundant                        # Remove redundant application dependencies
  -y, --yes                          # Automatically confirm changes
  --help                             # Show this help
